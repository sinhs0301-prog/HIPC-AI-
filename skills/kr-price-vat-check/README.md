# kr-price-vat-check (v2.2)

한국 부가가치세 10% 기준으로 **소계 / 부가세 / 합계** 세 숫자가 서로 맞는지 검산하는 에이전트 스킬입니다.
견적서·청구서를 작성하거나 검토할 때 계산 오류(5% 오적용, ÷1.1 역산 오차, 원단위 반올림 차이)를 잡아내는 용도입니다.

## 구성

| 파일 | 내용 |
|---|---|
| `SKILL.md` | 에이전트가 읽는 지침. 판정 규칙과 예시 입출력 |
| `vat_check.py` | 표준 라이브러리만 사용하는 검산 스크립트 (CLI) |
| `LICENSE` | MIT |

## 빠른 사용

```bash
python vat_check.py --subtotal 1250000 --vat 125000 --total 1375000
python vat_check.py --subtotal 33333 --vat 3333 --total 36666
python vat_check.py --total 1100000 --reverse
```

- `--reverse` 는 세금포함 합계에서 소계·부가세를 역산합니다.
- 기본 반올림은 원단위 `round half up` 이며 `--rounding floor|ceil` 로 바꿀 수 있습니다.
- 불일치가 있으면 종료코드 1, 일치하면 0 을 돌려주므로 다른 스크립트에서 조건 분기로 쓸 수 있습니다.

## 한계 (중요)

- 세무 자문이 아닙니다. 면세·영세율·간이과세·수입부가세·대손세액 공제 등은 다루지 않습니다.
- 10% 단일 세율 산술 검산만 수행합니다. 신고서 작성이나 전자세금계산서 발행 기능은 없습니다.
- 실제 신고 전에는 반드시 홈택스 또는 세무대리인의 확인을 받으십시오.
