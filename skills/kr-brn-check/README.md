# kr-brn-check — 한국 사업자등록번호 형식·체크섬 검증 스킬

에이전트/개발자가 고객이 입력한 **사업자등록번호 10자리**를 저장하거나 청구서에 찍기 전에,
오타를 즉시 걸러내기 위한 오프라인 검증 스킬입니다.

- 구성 파일: `SKILL.md`(에이전트용 지침), `brn_check.py`(표준 라이브러리만 사용하는 검증기), `LICENSE`
- 네트워크/API 키/외부 의존성 없음. Python 3 표준 라이브러리만.

## 무엇을 하는가
1. 입력 정규화: `123-45-67891`, `1234567891`, 공백 포함 입력을 숫자 10자리로 정리.
2. 길이·문자 검사: 숫자 10자리가 아니면 사유를 명시해 실패 처리.
3. 체크섬 검사: 가중치 `1,3,7,1,3,7,1,3,5`를 앞 9자리에 적용하고,
   9번째 자리에 대해서는 `(9번째 자리 × 5) // 10`을 추가로 더한 뒤
   `(10 - 합계 % 10) % 10`이 마지막 자리와 같은지 확인합니다.

## 무엇을 하지 못하는가 (중요)
- **실제 등록 여부·휴폐업 상태·과세유형은 알 수 없습니다.** 체크섬은 오타 탐지용입니다.
  실제 상태 확인은 국세청 홈택스 사업자상태 조회 등 공식 창구를 사용해야 합니다.
- 체크섬을 통과하는 번호가 반드시 존재하는 사업자는 아닙니다(예: `000-00-00000`도 규칙상 통과 가능).
- 법인등록번호(13자리), 주민등록번호와는 다른 규칙이므로 이 스킬로 검증하지 마십시오.

## 사용법
```bash
python brn_check.py 123-45-67891
python brn_check.py --file numbers.txt      # 한 줄에 하나씩
python brn_check.py --selftest              # 내장 검증
```

## 자체 검증 결과(재현 가능)
`--selftest`는 규칙에 맞는 번호를 생성한 뒤, 각 자리를 다른 숫자로 한 자리만 바꾼
**단일자리 오타 540건**을 만들어 검출률을 출력합니다. 저장소에 포함된 파일로 실행한 결과는
검출 540/540(1.0000), 미검출 0건이었습니다. 이 수치는 위 명령으로 누구나 재확인할 수 있습니다.
단일자리 오타에 강한 것은 체크섬의 성질이며, 두 자리 이상 동시 오타나 자리 교환은 통과할 수 있습니다.
