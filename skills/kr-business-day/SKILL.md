# kr-business-day — 한국 영업일/마감일 계산

## 언제 쓰나

에이전트가 한국 업무 문서(견적서, 발주서, 납기 안내, 신고 기한 안내)를 다룰 때
"영업일 기준 N일"을 실제 날짜로 환산해야 하는 경우. 모델이 암산하면
대체공휴일(예: 2026-08-15 광복절이 토요일 → 8/17 월요일 대체)을 빠뜨려
하루가 어긋나는 일이 흔하다. 이 스킬은 확정 공휴일 표를 내장해 그 오차를 없앤다.

## 사용법

```bash
python kr_business_day.py --add 2026-09-23 3
# 2026-09-23 기준 3영업일 마감은 2026-10-01(목)입니다. 달력일로 8일이며
# 제외된 날 5일: 2026-09-24 추석 연휴, 2026-09-25 추석, 2026-09-26 추석 연휴,
# 2026-09-27 주말(일), 2026-09-28 추석 대체공휴일

python kr_business_day.py --count 2026-09-01 2026-09-30   # 구간 영업일 수
python kr_business_day.py --next 2026-08-15               # 다음 영업일
python kr_business_day.py --list 2026                     # 공휴일 목록
python kr_business_day.py --selftest                      # 자체 검증
```

파이썬에서 직접 호출:

```python
from kr_business_day import add_business_days, business_days_between, deadline

add_business_days("2026-08-14", 1)        # date(2026, 8, 18)  광복절+대체 건너뜀
business_days_between("2026-09-01", "2026-09-30")  # 18
deadline("2026-09-23", 3)["text"]         # 사람에게 그대로 보여줄 문장
```

## 계산 규칙 (명시)

- 시작일 자체는 세지 않는다. `D+1영업일` = 시작일 다음 영업일.
- `n=0`이면 시작일이 영업일이면 그대로, 휴일이면 다음 영업일로 보정한다.
- 음수 n은 역산(마감일에서 거슬러 착수일 찾기)에 쓴다.
- 기본은 주5일. 토요일도 영업하면 `saturday_is_business=True`.
- `business_days_between`은 기본 (시작일 제외, 종료일 포함) 구간이다.

## 한계 — 반드시 사용자에게 전달할 것

1. **범위는 2026-01-01 ~ 2027-12-31뿐이다.** 범위 밖 날짜는 `OutOfRange`
   예외를 던진다(조용히 틀린 값을 주지 않는다). 다른 연도가 필요하면
   파일 상단 `HOLIDAYS` 표를 직접 추가해야 한다.
2. **음력 공휴일(설날·추석·부처님오신날)은 계산이 아니라 표로 적은 값이다.**
   정부가 임시공휴일을 추가 지정하면 표가 실제와 달라진다.
3. **법적 기한에는 그대로 쓰지 말 것.** 세금 신고·납부 기한은 국세청
   공고에 따른 별도 연장 규정이 있다. 이 도구는 참고 계산이며
   최종 확인은 관보/소관 기관 공고로 해야 한다.
4. 회사 창립기념일·하계휴무 등 개별 기업 휴무일은 반영되지 않는다.

## 검증 상태

`--selftest`가 표 무결성(모든 공휴일의 기재 요일과 실제 요일 대조)과
경계값을 함께 검사한다: 주말 경계, 설날 3일 연휴, 삼일절/광복절/추석/성탄절
대체공휴일, 대체공휴일이 없는 현충일, 월말·연말 넘김, 2027 설날 대체 2일,
n=0 보정, 음수 역산, 구간 합계, 범위 밖 예외, 입력 형식 파싱.
`RESULT: PASS`가 나와야 정상이다. 실패 항목은 개별로 출력된다.
