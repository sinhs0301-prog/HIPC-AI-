# kr-amount-words — 원화 금액 한글 표기 변환/검산

## 언제 쓰나
- 견적서·계약서·세금계산서·지출결의서에 "일금 삼백이십일만오천원정" 형식을 적어야 할 때
- 사람이 손으로 적은 한글 금액과 숫자 금액이 일치하는지 검산할 때
- 숫자만 있는 표에 한글 금액 칸을 자동으로 채울 때

## 실행 방법
```
python kr_amount_words.py 3215000
python kr_amount_words.py '일금 삼백만원정'
python kr_amount_words.py --verify 3000000 '일금 삼백만원정'
python kr_amount_words.py --selftest
```
- 숫자 인자: 정식/일반/1표기 세 가지 출력
- 한글 인자: 숫자로 역변환 + 권장 표기 출력
- `--verify 숫자 '한글'`: 일치하면 종료코드 0, 불일치하면 1 (검산용)
- `--selftest`: 내장 검사 전수 실행, 실패 0건이면 종료코드 0

## 파이썬에서 직접 호출
```python
from kr_amount_words import format_amount, korean_to_num, verify

format_amount(3215000)                 # '일금 삼백이십일만오천원정'
format_amount(3215000, style="plain")  # '삼백이십일만오천원'
korean_to_num('일금 삼백만원정')        # 3000000
verify(3000000, '일금 삼백만원')        # {'match': True, ...}
```

## 표기 규칙(중요)
- 만 단위 그룹의 선행 1은 생략한다. `10000 -> 만`, `10001 -> 만일`
- 억 이상 그룹의 선행 1은 항상 적는다. `100000000 -> 일억`, `10**18 -> 일백경`
  (계약 문서에서 '백경/일백경' 혼선을 막기 위한 선택이다)
- `explicit_one=True`를 주면 모든 그룹에서 1을 적는다. `1200 -> 일천이백`
- 역변환은 사람이 흔히 쓰는 축약형(`억`, `조`, `백경`, `억이천만`)도 해석한다.

## 한계 (반드시 읽을 것)
- 0 이상 10^20 미만의 **정수 원화**만 지원한다. 소수점(전 단위), 음수, 외화는 지원하지 않는다.
- 표기 관례는 기관·양식마다 다를 수 있다. 이 스킬은 특정 기관 양식 통과나 법적 효력을 보증하지 않는다.
- 세금 계산, 부가세 산정 기능은 없다. 금액 문자열 변환만 한다.
- 표준 라이브러리만 사용하며 네트워크 접근이 없다.

## 검증 방법
같은 폴더의 `kr_amount_words.py`를 `--selftest`로 실행하면 고정값 표기, 억 이상 선행 1 표기,
0~30000 전수 왕복, 난수 대액 왕복(형식 3종 × 1표기 2종), 경계값 왕복, 축약형 해석,
잘못된 입력 오류처리까지 15만 건 규모를 한 번에 검사한다.
실패 건수와 실패 내용이 그대로 출력되므로, 사용 전 직접 실행해 결과를 확인할 것을 권한다.
