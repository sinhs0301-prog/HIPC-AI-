# kr-amount-words

한국 원화 금액을 계약서·견적서·지출결의서에서 쓰는 한글 표기(`일금 삼백이십일만오천원정`)로 바꾸고, 반대로 사람이 적은 한글 표기를 숫자로 되돌려 **검산**하는 단일 파일 도구입니다.

- 언어: Python 3 (표준 라이브러리만 사용, 설치 불필요)
- 파일: `kr_amount_words.py` 하나
- 라이선스: MIT (본 저장소 작성자 직접 작성)

## 왜 필요한가

숫자 금액과 한글 금액이 서로 다르게 적힌 문서는 실무에서 자주 생기는 분쟁 원인입니다. 이 도구는
표기를 **생성**하는 데 그치지 않고, 이미 적혀 있는 한글 표기를 숫자로 **역해석해 대조**합니다.

## 사용법

```bash
# 숫자 -> 한글 표기
python kr_amount_words.py 3215000
# 정식: 일금 삼백이십일만오천원정
# 일반: 삼백이십일만오천원
# 1 표기: 일금 삼백이십일만오천원정
# 숫자: 3,215,000원

# 한글 표기 -> 숫자
python kr_amount_words.py '일금 삼백만원정'
# 숫자: 3,000,000원

# 숫자와 한글 표기 일치 검산 (불일치면 종료코드 1)
python kr_amount_words.py --verify 3000000 '일금 삼백만원정'

# 자체검사
python kr_amount_words.py --selftest
```

## 라이브러리로 쓰기

```python
from kr_amount_words import format_amount, korean_to_num, verify

format_amount(120000000)            # '일금 일억이천만원정'
korean_to_num('억이천만')            # 120000000
verify(3000000, '일금 삼백만원정')   # {'match': True, ...}
```

## 표기 규칙

- 만 단위 그룹은 선행 1을 생략합니다. `10000 -> 만`, `10001 -> 만일`
- 억 이상 그룹은 선행 1을 적습니다. `10**8 -> 일억`, `10**18 -> 일백경`
- `explicit_one=True`로 부르면 모든 그룹에서 1을 적습니다. `1200 -> 일천이백`
- 역해석은 `억`/`일억`, `백경`/`일백경` 같은 구표기도 모두 받습니다.

## 한계 (반드시 확인)

- **0 이상의 정수 원화만** 다룹니다. 소수점(전 단위), 음수, 외화는 지원하지 않습니다.
- 지원 범위는 `0 <= n < 10**20`(경 단위 4자리)입니다.
- 특정 기관 양식 통과나 법적 효력을 보증하지 않습니다. 최종 확인은 사용자 책임입니다.
- 표기 관례는 문서·기관마다 다를 수 있습니다. 위 규칙과 다른 관례를 요구하면 `explicit_one` 옵션으로 조정하거나 직접 수정해 쓰십시오.

## 검증 방법

`--selftest`는 고정값 대조, 억 이상 선행 1 표기, 만 단위 생략, 0~30000 전수 왕복 변환,
난수 대액 20000건 × 표기형식 3종 × 옵션 2종 왕복 변환, 경계값, 구표기 해석, 잘못된 입력 예외
처리를 함께 검사합니다. 검사 총 건수와 실패 건수를 출력하며 실패가 있으면 종료코드 1입니다.
실행 결과는 사용자가 직접 확인하십시오.
