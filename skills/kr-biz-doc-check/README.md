# kr-biz-doc-check

한국 사업 문서(견적서·계산서)를 사람이 최종 발송하기 전에 **오프라인으로 자가검산**하는 에이전트 스킬입니다.
네트워크 조회 없이 표준 라이브러리만으로 동작합니다.

## 무엇을 해결하나

- 사업자등록번호를 **체크섬 규칙**으로 검증해 오타를 발송 전에 잡습니다. (국세청 등록 여부 조회가 아님)
- 부가세 10% 계산이 맞는지 세 수치(소계·부가세·합계)를 대조합니다.
- 위 판단 기준과 절차는 `SKILL.md`에 정리되어 있습니다.

## 설치

별도 설치가 필요 없습니다. Python 3.9 이상이면 그대로 실행됩니다.

```bash
git clone https://github.com/sinhs0301-prog/HIPC-AI-.git
cd HIPC-AI-/skills/kr-biz-doc-check
```

에이전트 스킬로 쓸 때는 `SKILL.md`를 읽히고, 실제 숫자 검증이 필요할 때만
`scripts/brn_check.py`를 호출하도록 하면 됩니다.

## 사용 예시

자체 점검(내장 테스트 케이스로 판정 로직 확인):

```bash
python scripts/brn_check.py --selftest
```

사업자등록번호 한 건 검증:

```bash
python scripts/brn_check.py --number 120-814-7521
python scripts/brn_check.py -n 1208147521
```

> 주의: 위치 인자는 지원하지 않습니다. 반드시 `--number` 또는 `-n` 옵션을 사용하세요.
> (`python scripts/brn_check.py 1208147521` 은 인자 오류로 실패합니다.)

로그인·결제 없이 바로 읽고 내려받을 수 있습니다.

개별 문서 주소 대신 위 목록 페이지에서 확인해 주세요.

결제벽은 없습니다. 자료가 도움이 되었을 때만 자료실 페이지 안내에 따라

## 한계 (반드시 읽어주세요)

- 체크섬 검증은 **형식상 유효성**만 판정합니다. 실제 존재·휴폐업 여부는 국세청 확인이 필요합니다.
- 부가세 절차는 일반과세 10% 기준의 산술 검산이며, 세무 판단·신고 대행이 아닙니다. 사업상 판단은 세무사와 상담하세요.
- 어떤 수익이나 성과도 보장하지 않습니다.
